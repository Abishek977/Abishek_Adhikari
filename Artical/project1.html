4th Semester Survey Camp Project

A Practical Geomatics Engineering Project on Topographic Mapping

Project Overview

This project was part of the 4th Semester Survey Camp for Geomatics Engineering students at Pashchimanchal Campus, Lamachaur, Pokhara. The main objective was to learn and implement surveying techniques to create an interactive topographic map in ArcGIS. This hands-on experience provided students with practical knowledge of using Total Stations, leveling instruments, and GIS tools.

Key Objectives

  • Master the use of survey instruments like Total Station and leveling instruments.
  • Plan and execute a closed traverse survey for precise horizontal and vertical controls.
  • Learn data processing techniques in ArcGIS for creating detailed topographic maps.
  • Collaborate effectively in a group-based project environment.

Equipment and Methodology

  • Survey Instruments: Total Station, leveling instruments, ranging rods, and measuring tapes.
  • Software: ArcGIS for data processing and map generation, AutoCAD for drafting.

The methodology involved planning traverse stations, performing fly leveling, and collecting field data. The collected data was processed in ArcGIS to create a detailed map with contours and features.

Challenges and Learning Outcomes

Students faced challenges like difficult terrain and ensuring intervisibility between stations. These experiences honed their skills in problem-solving, teamwork, and using GIS tools effectively. The final interactive map provided valuable insights for urban planning and infrastructure development.
